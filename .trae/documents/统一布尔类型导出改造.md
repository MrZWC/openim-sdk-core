# OHOS 导出层统一布尔类型改造计划

## Summary

将 `cmd/ohos` 下所有"用 `int`/`C.int` 表达布尔语义"的对外 C 接口,统一改为 C99 的 `_Bool`/`bool`,使签名与 Android 端的布尔语义对齐,消除 0/1 手工转换。范围包含三类:**导出函数布尔参数**、**导出函数布尔返回值**、**回调函数指针签名布尔参数**。

> 技术基础:cgo 支持 `C._Bool`,Go `bool` 与 C `_Bool` 可双向转换;C 侧用 `<stdbool.h>` 的 `bool` 宏(等价于 `_Bool`)。

## Current State Analysis

当前所有布尔语义的对外参数/返回值均用 `int`/`C.int`(0/1)表达,调用处用 `!= 0` 或 `r:=0;if x{r=1}` 做转换。完整清单如下(基于实际代码扫描):

### A. 回调函数指针签名(`cmd/ohos/callback_types.h`)
- `on_sync_server_start_t(int reinstalled)` —— 第 45 行
- `on_sync_server_finish_t(int reinstalled)` —— 第 46 行
- `on_sync_server_failed_t(int reinstalled)` —— 第 48 行
- 对应 C 包装函数(第 219-230 行):`conv_cb_on_sync_server_start/finish/failed(..., int reinstalled)`
- 头部仅 `#include <stdint.h>`、`#include <stdlib.h>`,无 `<stdbool.h>`

### B. Go 回调桥接(`cmd/ohos/callback_bridge.go`)
- `OnSyncServerStart/Finish/Failed`(第 176/187/205 行):含 `r:=0; if reinstalled {r=1}` 再 `C.conv_cb_on_sync_server_*(l.cb, C.int(r))`

### C. 导出函数布尔参数(`//export OpenIM_*`)
| 函数 | 文件:行 | 参数 | 转换处 |
|------|---------|------|--------|
| OpenIM_SendMessage | conversation_msg_c.go:287 | isOnlineOnly C.int | isOnlineOnly != 0 |
| OpenIM_SendMessageNotOss | conversation_msg_c.go:294 | isOnlineOnly C.int | isOnlineOnly != 0 |
| OpenIM_ChangeInputStates | conversation_msg_c.go:424 | focus C.int | focus != 0 |
| OpenIM_ChangeGroupMute | group_c.go:63 | isMute C.int | isMute != 0 |
| OpenIM_SetAppBackgroundStatus | init_login_c.go:105 | isBackground C.int | isBackground != 0 |
| OpenIM_GetSpecifiedFriendsInfo | relation_c.go:31 | filterBlack C.int | filterBlack != 0 |
| OpenIM_GetFriendList | relation_c.go:39 | filterBlack C.int | filterBlack != 0 |
| OpenIM_GetFriendListPage | relation_c.go:47 | filterBlack C.int | filterBlack != 0 |

### D. 导出函数布尔返回值
- `OpenIM_InitSDK(...) C.int`(init_login_c.go:43):返回 1=成功 / 0=失败,内部 `if result {return 1}; return 0`

### 明确不改(真 int 语义,非布尔)
`progress`、`sessionType`、`index`、`logLevel`、`line`、`mutedSeconds`、`offset`、`count`、`errCode`、`totalUnreadCount`、`num`、`typ`、`OpenIM_GetLoginStatus` 返回值(1/2/3 状态码)。

## Proposed Changes

### 1. `cmd/ohos/callback_types.h`(回调签名 + C 包装函数)
- 顶部增加 `#include <stdbool.h>`
- 第 45/46/48 行:三个 typedef 的 `int reinstalled` → `bool reinstalled`
- 第 219/222/228 行:三个 C 包装函数参数 `int reinstalled` → `bool reinstalled`
- 理由:对外回调 ABI 直接表达布尔语义,与 Android 对齐

### 2. `cmd/ohos/callback_bridge.go`(Go 回调桥接)
- `OnSyncServerStart`(176-185):删除 `r:=0; if reinstalled {r=1}` 块,改为 `C.conv_cb_on_sync_server_start(l.cb, C._Bool(reinstalled))`
- `OnSyncServerFinish`(187-196):同上,改 `C._Bool(reinstalled)`
- `OnSyncServerFailed`(205-214):同上,改 `C._Bool(reinstalled)`
- 理由:去掉冗余 0/1 转换,直接传布尔

### 3. `cmd/ohos/conversation_msg_c.go`(导出函数布尔参数)
- `OpenIM_SendMessage`(287):`isOnlineOnly C.int` → `C._Bool`;调用处 `isOnlineOnly != 0` → `bool(isOnlineOnly)`
- `OpenIM_SendMessageNotOss`(294):同上
- `OpenIM_ChangeInputStates`(424):`focus C.int` → `C._Bool`;`focus != 0` → `bool(focus)`

### 4. `cmd/ohos/group_c.go`(导出函数布尔参数)
- `OpenIM_ChangeGroupMute`(63):`isMute C.int` → `C._Bool`;`isMute != 0` → `bool(isMute)`
- 同步更新第 64 行注释(原"1=禁言, 0=取消禁言,需转换为 Go bool 类型" → 表达直接布尔语义)

### 5. `cmd/ohos/init_login_c.go`(导出函数布尔参数 + 布尔返回值)
- `OpenIM_SetAppBackgroundStatus`(105):`isBackground C.int` → `C._Bool`;`isBackground != 0` → `bool(isBackground)`
- `OpenIM_InitSDK`(43):返回类型 `C.int` → `C._Bool`;内部 `if result {return 1}; return 0` → `return C._Bool(result)`
- 同步更新第 40 行注释("返回: 1 表示成功,0 表示失败" → "返回: 布尔值,true 表示成功")

### 6. `cmd/ohos/relation_c.go`(导出函数布尔参数)
- `OpenIM_GetSpecifiedFriendsInfo`(31):`filterBlack C.int` → `C._Bool`;`filterBlack != 0` → `bool(filterBlack)`
- `OpenIM_GetFriendList`(39):同上
- `OpenIM_GetFriendListPage`(47):`filterBlack C.int` → `C._Bool`;`filterBlack != 0` → `bool(filterBlack)`(注意 offset/count 仍为 C.int32_t 不变)
- 同步更新各处 filterBlack 注释

### 7. 构建产物 `build/ohos/arm64-v8a/libopenim_sdk.h`
- 该文件是 cgo 构建生成产物(含 `callback_types.h` 展开内容 + `//export` 函数签名)
- **不手动编辑**:完成上述源码修改后,重新执行 OHOS arm64-v8a 构建命令,cgo 会自动重新生成 `_cgo_export.h` 并刷新 `libopenim_sdk.h`
- 生成后预期:回调 typedef 中 `reinstalled` 变为 `bool`;导出函数 `OpenIM_*` 的布尔参数/返回值变为 `_Bool`

## Assumptions & Decisions

1. **cgo `_Bool` 支持**:确认 Go cgo 支持 `C._Bool` 与 Go `bool` 双向转换,无需额外桥接。导出函数签名在生成的 `_cgo_export.h` 中以 `_Bool` 呈现(C 惯例),`callback_types.h` 中用 `bool` 宏(可读性更好)。
2. **转换写法**:Go 侧统一用显式 `bool(x)` / `C._Bool(x)`,而非依赖隐式转换,保持代码清晰并符合现有注释风格。
3. **ABI 破坏性变更**:本次改动是破坏性 ABI 变更(`int` 4 字节 → `_Bool` 1 字节)。OHOS 侧 NAPI 桥接代码(不在本仓库)需同步从 `napi_get_value_int32`/`napi_create_int32` 改为 `napi_get_value_bool`/`napi_create_bool`。本计划仅覆盖 Go/C 源码侧。
4. **`OpenIM_GetLoginStatus` 不改**:返回值是 1/2/3 状态码,非布尔,保持 `C.int`。
5. **真 int 参数不改**:所有非布尔语义的 int(进度、索引、秒数、分页、错误码等)保持不变。
6. **注释同步**:按用户规则,关键参数/步骤保持中文注释,涉及语义变化的注释(如 isMute、InitSDK 返回值)一并更新。

## Verification Steps

1. **编译验证**:对 `cmd/ohos` 执行 OHOS arm64-v8a 交叉构建,确认无编译错误(cgo 类型转换正确)。
   - 命令示例:`go build -target=ohos/arm64-v8a ./cmd/ohos`(按项目实际构建脚本执行)
2. **产物检查**:重新生成后,检查 `build/ohos/arm64-v8a/libopenim_sdk.h`:
   - `on_sync_server_start_t`/`finish_t`/`failed_t` 的参数为 `bool reinstalled`
   - `OpenIM_SendMessage` 等导出函数的布尔参数为 `_Bool`
   - `OpenIM_InitSDK` 返回类型为 `_Bool`
3. **转换逻辑检查**:确认 `callback_bridge.go` 中三个 `OnSyncServer*` 不再有 `r:=0;if...{r=1}` 残留;各 *_c.go 中不再有对应的 `!= 0` 残留。
4. **回归点**:确认 `OpenIM_GetLoginStatus`(状态码)、`OpenIM_ChangeGroupMemberMute`(mutedSeconds 秒数)等真 int 接口未被误改。
